## Project Overview

**Web Noter** is a single-file HTML application (`web-noter.html`) for writing Markdown notes stored on GitHub. No build step, no dependencies, no backend — open the file in a browser and it works.

## Development

No build, lint, or test commands. The entire application is one file:

```
web-noter.html   ← the whole app (HTML + CSS + JS)
README.md        ← end-user documentation
```

To develop: edit `web-noter.html`, open it in a browser via `file://`, test manually against a real GitHub repo.

## Architecture

Everything lives in `web-noter.html` in three sections:

**CSS** (`:root` CSS variables → Catppuccin Mocha dark theme)

**HTML layout** (flex column):
- `#meta` — 3-column grid: filename / source URL / tags
- `#toolbar` — list files, apply templates
- `#editor` — single `<textarea>` (the only editing surface)
- `footer` — append / load / overwrite buttons + status

**JavaScript** (no frameworks, inline `<script>`):

| Layer | Key functions |
|-------|--------------|
| Config | `getConfig()` reads `localStorage` keys `wn_pat/owner/repo/branch/prefix` |
| GitHub API | `githubRequest(method, path, body)` — base wrapper; all content is base64-encoded via `btoa(unescape(encodeURIComponent()))` |
| Write ops | `appendToGitHub()` (GET→append→PUT), `overwriteToGitHub()` (GET SHA→PUT raw), `saveToGitHub()` (PUT with frontmatter — **defined but not wired to any button**) |
| Read ops | `loadFromGitHub()` → `parseContent()` extracts YAML frontmatter into Meta fields |
| List | `listFromGitHub()` — fetches directory contents then fires one commits API call per `.md` file in parallel for last-modified date |
| Templates | `TEMPLATES` object; `applyTemplate(key)` fills editor + filename |

**Frontmatter** is auto-generated by `buildContent()` and written by append/save operations. `overwriteToGitHub()` skips frontmatter and writes raw editor content.

**Dirty tracking**: `isDirty` flag + `●` indicator in header title; `markClean()` resets both.

**Ctrl+S** is bound to `appendToGitHub()`, not save/overwrite.
